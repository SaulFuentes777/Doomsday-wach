# DOOMSDAY WATCH

Web app móvil para seguir las noticias de Avengers: Doomsday.

Publicar gratis: Settings → Pages → Source = GitHub Actions. En Actions, ejecutar «Actualizar y publicar Doomsday Watch». Enlace esperado: https://saulfuentes777.github.io/Doomsday-wach/ . En Safari → Compartir → Agregar a pantalla de inicio.

La revisión automática por GitHub Actions se solicita cada hora y puede retrasarse. La app refresca datos cada cinco minutos mientras está abierta. No proporciona notificaciones push propias; los avisos de ChatGPT son independientes.
